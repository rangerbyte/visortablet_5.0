Mapa de fondo ✕

Capas superpuestas

Deslízalo a la izquierda para difuminar el mapa base y que se vean mejor las capas WMS superpuestas (ortofoto, satélite, etc.).

Ortofoto de fondo

La ortofoto va por debajo de los mapas vectoriales (.osm.map) y de los MBTiles. Para verla a través de ellos, baja la transparencia del mapa de fondo con el deslizador de arriba.

Mapas MBTiles

Un archivo .mbtiles (exportado p. ej. desde QGIS) se guarda en esta tableta. Puedes tener varios encendidos a la vez: se dibujan sobre el mapa de fondo, en el orden en que los enciendes. Con 🔍 la vista va hasta el mapa y con 🗑️ se borra de la tableta.

Con 📋 se trae el mapa copiado en otra aplicación (el explorador de archivos, Drive, Files…) sin tener que buscarlo con 📂, por grande que sea. También vale un enlace de descarga copiado del navegador.

Mapas vectoriales OSM (.map)

Un archivo .osm.map (formato Mapsforge, el de OruxMaps, Locus u OpenAndroMaps) trae los datos de OpenStreetMap en vectorial, no imágenes: una provincia entera ocupa unas decenas de MB y se dibuja aquí mismo, sin conexión, con pistas, sendas, arbolado, agua, curvas de nivel y topónimos. Se enciende y se apaga igual que los MBTiles.

Uso sin conexión

Descarga los mosaicos del mapa de fondo actual para la zona que ves en pantalla y los dos niveles de zoom siguientes, y los guarda en la tableta. Después esa zona se verá aunque no haya cobertura. Encuadra bien antes de pulsar: cuanto más alejado el zoom, más superficie y más descarga.

Carpeta de trabajo ✕

Los puntos, líneas y áreas que levantes se guardan agrupados en una carpeta, para tenerlo ordenado por trabajo (un incendio, un deslinde, una jornada de campo…). Todo lo que dibujes va a la carpeta activa hasta que la cambies aquí. Cada carpeta se puede exportar entera a KMZ con el botón 📦.

➕ Crear sin escribir nada propone la fecha de hoy · ✏️ cambia el nombre · 🗑️ borra una carpeta vacía · ❔ arriba, la explicación entera.

Elementos del mapa ✕

Proyectos ✕

Empieza un proyecto nuevo (vacío, con nombre) o guarda el trabajo actual (puntos, líneas y polígonos) como un proyecto con nombre, para poder recuperarlo más tarde o sincronizarlo entre tus dispositivos con la opción de abajo.

Proyectos guardados

Cada proyecto se guarda en este dispositivo. Con ⬇️ puedes descargarlo como archivo .json (copia de seguridad o para pasarlo a otro dispositivo), y con el botón de abajo puedes cargar un proyecto desde un archivo .json.

Sincronización en la nube (opcional)

Sincroniza automáticamente tus proyectos entre dispositivos usando una base de datos gratuita de Firebase (Google). Se configura una sola vez:

1. Entra en console.firebase.google.com y crea un proyecto (gratis).
2. Crea una base de datos Firestore (modo producción, cualquier región).
3. En la pestaña "Reglas" de Firestore, sustituye el contenido por esto y publica:
rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /campoAgentesSync/{syncCode} { allow read, write: if true; } } } 4. En "Configuración del proyecto" → tus apps, registra una app Web y copia el objeto firebaseConfig.
5. Pégalo abajo junto con un código de sincronización (invéntate uno largo y compártelo solo entre tus dispositivos: funciona como contraseña).

Importar archivo ✕

Carga un archivo KMZ, KML, GPX, GeoJSON o un ZIP tal cual te lo descargues del navegador: se abre y se importa todo lo que lleve dentro, sean shapefiles (.shp + .dbf + .prj), KMZ, KML, GPX o GeoJSON, aunque vengan en carpetas o en otro ZIP. Sus puntos, líneas y polígonos se añadirán al mapa y a la lista de elementos, donde podrás cambiarles el nombre y el color.

Pegar sirve para tres cosas: un archivo copiado (en el Finder o en el explorador, con ⌘C / Ctrl+C), el enlace de descarga de un KMZ/KML/GPX/GeoJSON/ZIP copiado del navegador, o el texto de un KML o un GeoJSON copiado de una página. También puedes pegar con ⌘V / Ctrl+V sobre el mapa, sin abrir esta ventana.

Buscar municipio ✕

Marcadores ✕

Guarda el sitio que estás mirando —con su encuadre— y vuelve a él de un toque: la base, el vivero, el cruce de pistas… No dibuja nada en el mapa ni se mezcla con los puntos, líneas y áreas: es una lista de sitios a los que ir.

Buscar parcela SIGPAC ✕

Referencia catastral de una parcela rústica (14 dígitos, o 20 si incluye subparcela). Se localiza en el Catastro, se traduce a códigos SIGPAC y se dibuja la parcela completa.

Agregado y zona casi siempre son 0; sólo se cambian si el código de la parcela los lleva. Recinto vacío = se dibuja la parcela completa.
